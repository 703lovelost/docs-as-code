# Model Card

## Общая информация

**Название модели:** google/efficientnet-b7

**Источник:** <a href="https://huggingface.co/google/efficientnet-b7">https://huggingface.co/google/efficientnet-b7</a>

**Автор / организация:** Google

**Задача модели:** Классификация изображений

**Язык:** Английский

## Использование в проекте

Модель используется для автоматического определения категории изображений, загружаемых пользователями.

Изображение передаётся модели после отправки пользователем. Полученный результат сохраняется системой и отображается оператору разметки.

Реализация осуществляется в соответствии со <a href="/project/requirements">сценариями использования</a>.

## Входные данные

**Тип данных:** цифровое изображение.

**Цветовое пространство:** RGB (3 канала).

**Размер изображения:** 600×600 пикселей после предварительной обработки.

**Предобработка:** изменение размера, нормализация значений пикселей и преобразование изображения в тензор.

## Выходные данные

Модель возвращает результат классификации изображения:

* **Категория (category):** наиболее вероятный класс изображения.
* **Уверенность (confidence):** оценка вероятности принадлежности изображения к выбранному классу, число от 0 до 1.

## Метрики качества

Фактические значения метрик на данных проекта должны быть определены экспериментально после тестирования модели.

В публикации EfficientNet-B7 заявлена метрика **Top-1 Accuracy 84,3%** на ImageNet-1k.

## Ограничения

Потенциальные ограничения для модели:

* Модель обучена на `ImageNet-1k` и может некорректно классифицировать изображения, не относящиеся к известным категориям.
* Качество классификации может снижаться при низком разрешении, наличии шумов, размытия или существенных искажений изображения.
* Модель может ошибаться при наличии нескольких объектов разных категорий на одном изображении.

## Не рекомендуется использовать

Модель не рекомендуется использовать в следующих случаях:

* Для определения категорий, отсутствующих в обучающем наборе данных, без дополнительного дообучения.
* Для классификации медицинских изображений без специализированного обучения и валидации.
* Для автоматической доразметки данных без контроля качества со стороны оператора.
