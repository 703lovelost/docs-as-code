# Data Sheet

## Общая информация

**Название датасета:** ILSVRC/imagenet-1k

**Источник:** <a href="https://huggingface.co/datasets/ILSVRC/imagenet-1k">https://huggingface.co/datasets/ILSVRC/imagenet-1k</a>

**Автор / организация:** ImageNet / ILSVRC

**Назначение:** Обучение и оценка моделей машинного обучения для автоматической классификации изображений по заранее определённым категориям.

## Состав данных

**Объём:** 1 431 167 изображений, распределённых по трём выборкам:

* **Обучающая (train)** — 1 281 167 изображений.
* **Валидационная (validation)** — 50 000 изображений.
* **Тестовая (test)** — 100 000 изображений.

**Тип данных:** Цветные цифровые изображения с различными разрешениями.

**Основные поля / признаки:** 

* *image* — исходное изображение.
* *label* — числовой идентификатор категории изображения (от 0 до 999).

Категории соответствуют иерархии WordNet. Для тестовой выборки метки классов не предоставляются и представлены значением -1.

## Получение данных

Данные были собраны в рамках проекта ImageNet из изображений, размещённых в интернете.

Процесс формирования набора данных включал:

* Поиск изображений, соответствующих категориям из WordNet.
* Отбор изображений для каждой категории.
* Ручную проверку и разметку изображений с привлечением аннотаторов.
* Формирование обучающей, валидационной и тестовой выборок.

Для обеспечения качества использовалась проверка соответствия изображений назначенным категориям.

## Предобработка

На уровне датасета предобработки изображений не представлено.

## Ограничения

Для датасета действуют следующие ограничения:

* Изображения преимущественно получены из интернета и могут не соответствовать условиям реальной эксплуатации модели.
* Набор данных может содержать дисбаланс классов.
* Для использования датасета действуют ограничения правообладателей: доступ предоставляется для некоммерческих исследовательских и образовательных целей.

## Использование в проекте

Датасет ImageNet-1k используется как исходный набор данных, на котором была обучена модель google/efficientnet-b7, выбранная для автоматической классификации изображений.
