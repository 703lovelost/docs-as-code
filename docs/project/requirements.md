# Функциональные требования

## User Stories

### US-01. Отправка изображения

| Как | я хочу | чтобы |
| --- | --- | --- |
| пользователь | автоматически отправлять изображения | получить его категорию. |

Критерии приемки US-01:

- система принимает изображение;
- система отображает категорию по факту обработки модели;
- если обработка моделью недоступна, пользователь получает сообщение об ошибке.

### US-02. Определение категории изображения

| Как | я хочу | чтобы |
| --- | --- | --- |
| пользователь | автоматически получать категорию изображения | убедиться в качестве работы модели. |

Критерии приемки US-02:

- система автоматически определяет категорию изображения с помощью модели;
- система возвращает категорию из заранее определённого списка классов;
- если модель не может определить категорию изображения, пользователь получает соответствующее сообщение.

### US-03. Просмотр результата классификации

| Как | я хочу | чтобы |
| --- | --- | --- |
| оператор разметки | просматривать классифицируемые изображения | подтвердить/отклонить их классификацию. |

Критерии приемки US-03:

- система отображает оператору разметки изображение и присвоенную ему категорию;
- система предоставляет возможность просмотра изображений, ожидающих проверки;
- система отображает текущий статус проверки классификации изображения.

### US-04. Утверждение/отклонение результата классификации

| Как | я хочу | чтобы |
| --- | --- | --- |
| оператор разметки | подтверждать/отклонять классификацию изображения | отправить изображение в данные для дообучения. |

Критерии приемки US-04:

- оператор разметки может подтвердить или отклонить присвоенную изображению категорию;
- при отклонении классификации оператор может указать корректную категорию;
- система сохраняет решение оператора и обновляет статус проверки изображения;
- система добавляет проверенное изображение с подтверждённой или исправленной категорией в набор данных для последующего дообучения модели.

## Use Cases

### UC-01. Отправка изображения на классификацию

__Актор:__ пользователь.

__Цель:__ отправить изображение и получить его категорию.

__Предусловие:__ пользователь открыл интерфейс отправки изображения.

__Основной сценарий:__

1. Пользователь загружает изображение в систему.
2. Система принимает изображение и передаёт его ML-модели.
3. ML-модель обрабатывает изображение и определяет его категорию.
4. Система получает результат классификации.
5. Система отображает пользователю определённую категорию изображения.

__Альтернативный сценарий:__

- Если ML-модель недоступна или не может обработать изображение, система сообщает пользователю об ошибке классификации.

__Результат:__ категория изображения определена и отображена пользователю либо пользователь получил сообщение об ошибке.
