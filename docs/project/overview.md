# Классификатор изображений

Сервис автоматически определяет категорию, к которой относится изображение и отправляет его на валидацию команде разметки.

Основные роли:

- пользователь;
- оператор разметки.

Основные функции:

- отправка изображения;
- определение категории изображения;
- просмотр результата классификации;
- утверждение/отклонение результата классификации.
